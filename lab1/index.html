Format

Titles can be counted more than once. A co-production counts once for each country it lists, and a title counts once for each of its genre tags — so the bars add up to more than 100%.

Every bar shares one denominator: all titles from the selected country added in the selected years, both formats. Movie and TV bars are therefore directly comparable. Genre tags are format-specific — Dramas only ever tags films, TV Dramas only TV — so each genre appears once, in one colour; none has both a movie and a TV bar.

Source & method

  • Kaggle Netflix Movies and TV Shows, a catalogue snapshot taken September 2021 ( titles). Aggregated to country × genre × year × format and embedded in this file; the page loads nothing.
  • Time is date_added — when Netflix added a title — not release_year. The year control filters that range; this page does not chart year-by-year change.
  • rating and duration are not used.
